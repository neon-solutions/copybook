The install commands on this site use Command Tabs. A tab can also hold an agent prompt, like the first tab here:

<GetStartedDemo />

Install it:

<InstallCommand item="command-tabs" />

## Usage

Make the package manager a param, then render one tab per value:

```tsx
import { render } from "@copybook/core";

import { CommandTabs } from "@/components/copybook/command-tabs";
import { init, setupPrompt } from "@/content/definitions/get-started";

const managers = ["pnpm", "npm", "yarn", "bun"] as const;

export const GetStarted = () => (
  <CommandTabs
    defaultTab="pnpm"
    tabs={[
      {
        id: "prompt",
        kind: "prompt",
        label: "Prompt",
        rendered: render(setupPrompt),
      },
      ...managers.map((packageManager) => ({
        id: packageManager,
        label: packageManager,
        rendered: render(init, { packageManager }),
      })),
    ]}
  />
);
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `tabs` | `{ id, label, rendered, kind? }[]` | One tab each, in order. `kind: "prompt"` wraps long lines and adds an agent icon. |
| `defaultTab` | `string` | The tab that starts selected. |
| `onCopy` | `(event: CopyEvent) => void` | Called with `{ id, text }` after a copy. |
