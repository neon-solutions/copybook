## Unreleased: 0.1.0

The first release.

- **`@prompt-manager/core`**:
  - `defineCommand`, `defineSnippet` (with dimensioned variants), `definePrompt`, and `defineCollection`
  - the `p` param builders, with examples, defaults, secrets, and Standard Schema
  - the `t` template tag, with param nodes and `t.cmd`, `t.code`, and `t.include` embeds
  - `render`, `renderExample`, `listVariants`, `toText`, `toSegments`, `collectCommands`, and `collectEmbeds`
- **`@prompt-manager/cli`**:
  - `init`, `list`, `snapshot`, and `check`, with rendered Markdown snapshots and `--changed` change detection
  - `test`, with syntax, typecheck, and run tiers, fixtures, and JSON and JUnit reports
  - `eval`, with agent adapters (`literal`, `claude-code`, `codex`), PATH shims, assertions, trials, budgets, and history
  - `studio`, a local UI for browsing, previewing, and tracing definitions
- **Registry**: Agent Prompt, Code Variants, Command Tabs, Copy Button, and Rendered Text.
