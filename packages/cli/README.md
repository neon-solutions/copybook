# @copybook/cli

Catalog, snapshot, test, and evaluate the code snippets and agent prompts in your product.

> Copybook is at 0.x, so minor releases can include breaking changes. The [changelog](https://github.com/neon-solutions/copybook/blob/main/content/docs/changelog.mdx) lists them.

```bash
npx @copybook/cli init
```

The [docs](https://copybook.dev/docs) start with a [quick start](https://copybook.dev/docs/quick-start). The [CLI reference](https://copybook.dev/docs/reference/cli) lists every command and flag.
